# AutoMix .8：连续尾音的原速短交接

本轮继续研究用户提供的 Java `automix` 和 C `automix-c`，增加独立的短尾音路径 `release-boundary`，规划版本更新为 `twilight-rules-5`。参考代码未移入产品。分轨增强开关及自动 / GPU / CPU 选择沿用 .7；本轮统计针对关闭分轨的基础 AutoMix。

## 参考实现与本项目的判断

Java `RouteGates.java` 的 `CROSSFADE_OVERLAP` / `CROSSFADE_RINGOUT` 系列分别判断尾段长度和两首歌的响度关系，说明尾音交接可以独立于对拍路径。`AutoCue.java::evaluate` 用实际渐变增益检查混合包络、低频与局部人声重叠。C `src/am_scoring.c::am_evaluate_candidate` 对尾段长度、响度关系和已知 / 缺失证据分别处理；`windows/contracts/pair-eligibility-contract.md` 保持来源绑定与调用方策略独立。

这些设计用于确定本项目需要验证哪些证据，没有直接采用参考实现的阈值或把其源码当作音频验收结果。本项目已有内容尾奏路径要求交接跨度内存在正音乐分类，持续衰减的音乐余音可能失去该标签。补充路径要求近邻音乐证据和连续音频包络同时成立，避免把未知或静音当作音乐。

## 进入条件

补充路径只在已有对拍、内容尾奏和 DJ 长尾奏路径均失败后运行，因此不会重新排名已有的成功计划。

- 两侧边界、完整人声覆盖与全频 / 低频分析必须已知。淡出后半段和淡入前半段的人声上限仍为 0.08；下一首必须有正音乐证据。
- 在淡出开始前最多 8 秒内寻找至少 0.5 秒活跃正音乐证据，证据所在一秒的全帧能量高于 −40 dB。证据到淡出起点的覆盖连续且无明显人声。
- 从证据到真实歌尾，半秒全频能量不得回升超过 3 dB，半秒低频峰值不得回升超过 4 dB。交接中段的全频 / 低频瞬态还需通过既有稀疏检查。
- 当前曲进入交接时能量高于 −40 dB，尾音至少衰减 12 dB；下一首退出交接时高于 −50 dB，两端差不超过 12 dB。
- 根据实际等功率渐变及下一首增益恢复曲线评估逐秒混合包络，偏离两端线性 dB 轨迹不超过 5 dB，并要求至少一秒共同可听。DJ 长尾奏路径仍要求至少半个跨度共同可听。
- 时长仅为 2–8 秒，两首均保持原速，不增加特效，节拍与置信度诚实保持零。保留实际歌尾和下一首开头，仅移除已有规则证实的边界静音。
- 继续遵守当前播放位置、来源 SHA-256、队列 / 播放 / 格式版本绑定和 128 MiB 完整准备内存上限。新的规则版本使旧策略缓存失效。

## 冻结样本结果

同一份随机预选的 36 对真实歌曲，语料 SHA-256：`ee2c8f460725307331ee76fe866ef0a4b1d9ea332083eb6b8fc595827cb31520`。复用原始模型分析窗口，逐一核对源文件与窗口摘要，经生产 C++ JSON 解析和窗口合并后选择及渲染。

| 指标 | .7 基础规划 | .8 |
| --- | --- | --- |
| Natural 智能准备 | 26 / 36（72.2%） | 27 / 36（75.0%） |
| DJ 智能准备 | 34 / 36（94.4%） | 34 / 36（94.4%） |
| DJ ≥16 秒 | 22 / 36（61.1%） | 22 / 36（61.1%） |

新增 `pair-27` 的 Natural 原速 8 秒尾音交接，两首为“かめりあ - Hello (BPM) 2024”→“AIKA - Gensokyo”。真实解码立体声、实际准备增益与限幅后的共同可听跨度为 4.50 秒，混合包络偏离为 3.990 dB。其余成功计划的策略、时长、源边界、速度与特效保持一致。

`pair-33` 的尾音也在衰减，但下一首开头形成明显包络空洞，继续回退。其余未覆盖组合仍受人声、节奏或衰减证据约束。本轮没有以提高时长或放宽人声门槛来增加计数。

这些是准备和渲染计数，不能等同于人工听感通过，也不是对预先标注“适合混音组合”的覆盖率。

## 复现

使用 `tools/evaluate_rules3.py`，显式传入 `--rule-version twilight-rules-5`，`--baseline` 指向保留的原始模型窗口，`--comparison` 指向 .5 音频对照。该对照的基础规划与 .7 相同。`--probe` 和 `--windows-probe` 必须来自本轮构建的原生测试程序，输出分别保存到新的交付目录和 scratch 目录，保留历史评估结果。
