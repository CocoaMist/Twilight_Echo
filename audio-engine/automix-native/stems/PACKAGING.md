# Windows stem inference package

The package contains the pinned Python/PyTorch/torchaudio runtime and Demucs
checkpoint described by [model.lock.json](./model.lock.json).
Worker behavior and cache ownership are specified in [RUNTIME.md](./RUNTIME.md).

## Staging policy

`package_windows.py` stages an inference distribution rooted at
`automix-enhancement` and copies its adjacent `worker.py` into that stage.
Manifest fields `packageVersion`, `distribution` and `compilerSdkIncluded`
describe the distribution.

Staging omits static/import libraries, debug symbols, compiler headers/CMake
files, dependency tests, type-checker stubs, pip implementation and generated
bytecode. It retains inference import modules, distribution metadata, legal
notices and every DLL, PYD, EXE and TH from the source package, including CUDA
payloads and supported GPU architectures. `torch.testing` is retained.

`package-files.json` records SHA-256 and byte counts. The inventory excludes
itself, archive metadata and generated bytecode. Retained runtime/model files
must match the source digests; the stage report records omissions and reasons.

## Create an archive

Run with Python 3.11 and new staging/output paths from this directory:

```powershell
python package_windows.py stage --source D:\source-pack --stage D:\new-stage --report D:\stage-report.json
python package_windows.py 7z --stage D:\new-stage --output D:\enhancement.7z --seven-zip 'C:\Program Files\7-Zip\7z.exe' --report D:\archive-report.json
```

The 7z action uses lossless LZMA2, a 64 MiB dictionary, four compression threads
and 512 MiB solid blocks. The `zip` action produces a standard DEFLATE level-9
ZIP for the player's local ZIP installer. Both actions test the completed
archive and refuse to overwrite an existing output. The pinned model is not
quantized, retrained or reserialized.

## Verify the result

Extract into a new empty directory, validate retained-file digests and run
the package's embedded Python from a different working directory. Verify
CPU/stereo, GPU/stereo where supported, CPU/mono, cache reuse, GPU failure
fallback, corrupt/missing models, timeout, finite output and original-PCM context.

Keep source-pack inputs and verification reports outside the checkout.
