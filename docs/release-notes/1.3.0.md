# Twilight Echo v1.3.0

_更顺手地发现音乐，更细致地调整声音，也更方便地保存自己的音乐记录。_

1.3.0 重点更新了日常浏览、在线发现、设置与外观定制，并补齐后台任务、软件更新和个人数据迁移流程。同时，对播放交接、歌词、曲库、统计存储和原生音频处理进行了多轮修复与性能优化。

> [!NOTE]
> **对比范围：1.2.4 → 1.3.0。** 本说明以 **1.2.4 正式版** 为对比基线。1.2.4 已有的播放会话恢复、连续播放策略、交叉淡化规则、DSP 等响度 A/B 试听、曲库整理收件箱、版本管理和收听统计在本次继续完善。

## 本次更新重点

- **统一导航与独立搜索**：重新组织本地音乐与在线音源入口，支持页面排序、隐藏、状态恢复，以及本地和网易云专辑搜索。
- **在线主页与排行榜**：本地曲库为空时也能浏览在线内容；加入网易云排行榜入口，改进最近播放、推荐和歌单浏览。
- **任务与通知中心**：在标题栏集中查看扫描、补全、响度分析、下载和软件更新，提供进度、处理操作、通知记录与勿扰模式。
- **个人数据备份与迁移**：支持十类个人数据导出、恢复预览、选择性恢复、冲突处理和音乐目录映射。
- **更完整的软件更新流程**：加入校验后的下载恢复、断点续传、下载进度、更新频道、提醒偏好和安装结果确认。
- **背景与界面材质编辑器**：统一管理页面背景、深浅色方案、透明／毛玻璃／液态玻璃材质，并支持全窗口预览。
- **设置与首次使用流程重整**：设置按七个用途分类，增加快速配置，改进搜索定位、基础与高级选项分组、音频试听和引导总结。
- **播放稳定性与性能优化**：修复保存音量恢复、旧播放事件干扰、DSP 场景保持、网易云相邻曲目准备、歌词缓存和大队列重复处理等问题。
- **Twilight AutoMix 自动混音**：开放自然与 DJ 模式，支持歌曲边界分析、对拍和分轨增强；GPU 等分轨运行包作为独立附件提供。

## 新增与扩展功能

_从寻找一张专辑，到下载后加入曲库，再到换机迁移，补齐日常使用中的衔接步骤。_

### 1. 统一页面导航

_常用页面按自己的习惯排列，返回页面时继续上次的浏览位置。_

- 侧栏按用途组织在线音乐和本地音乐库，减少不同来源之间的导航混淆。
- 在线音乐分支提供推荐主页、发现歌单、平台音乐库和音乐云盘等入口。
- 本地音乐库保留所有歌曲、专辑、艺术家、应用歌单、文件夹和流派入口。
- 新增**页面管理**，可调整页面顺序、隐藏不常用页面，并恢复默认配置。
- 页面管理同时支持拖动排序与按钮操作。
- 隐藏的页面仍可通过页面选择或命令面板打开，无需先修改侧栏配置。
- 展开或收起导航分组时保留当前页面、搜索状态和播放状态。
- 不同在线页面分别保留音源、筛选条件、详情层级和滚动位置。
- 本地列表的查询与视图偏好按具体页面、专辑、歌单或目录区分。
- 改进重启后的页面恢复，覆盖内置页面、本地详情及前台工具状态。
- 插件页面等待对应插件入口就绪后恢复，避免启动时过早跳转到不可用页面。
- 修复启动恢复与用户主动导航之间的竞争，优先保留用户刚做出的选择。

### 2. 独立搜索页与专辑搜索

_一个搜索入口，覆盖本地曲库和支持对应搜索能力的在线音源。_

- **独立搜索页**统一承接歌曲、专辑、歌单和艺术家搜索。
- 可选择全部来源、本地音乐，以及支持当前搜索类型的已启用音源。
- 新增**本地专辑搜索**，支持专辑名、专辑艺术家、拼音首字母和多个关键词组合。
- 新增**网易云专辑搜索**；未登录时可请求公开专辑信息，登录后沿用当前账号状态。
- 专辑结果显示艺术家和来源，打开时使用结果所属音源。
- 不同来源的同名专辑，以及不同艺术家的同名本地专辑，保持各自独立身份。
- 本地专辑详情沿用曲库中的碟号与曲目顺序。
- 从搜索结果进入专辑或艺术家详情后，返回时保留关键词、音源和分页位置。
- 歌曲结果可继续打开对应艺术家与专辑页面。
- 修复快速连续操作时，旧元数据请求可能把页面带到先前歌曲详情的问题。
- 改进网易云专辑相关的歌单操作，使用当前账号实际可操作的歌单。
- 修复聚合搜索的分页边界，按各来源的实际结果数量判断是否还有下一页。
- 某一来源查询失败时保留其他来源的成功结果，并标明失败来源。
- 新查询、页面离开或关闭搜索后，旧响应不再覆盖当前结果、加载状态或错误提示。
- 命令面板继续支持 **Ctrl／⌘ + K**，并扩展歌曲与已加载歌单的搜索入口。
- 空查询显示常用操作；以 `>` 开头的查询可只查找操作和设置。
- 命令面板中的歌曲使用正常播放路径，歌单进入对应详情；打开设备、EQ 或 DSP 设置不会直接应用配置。
- 改进中文输入法组合输入、方向键选择、Enter 执行、Escape 关闭及关闭后的焦点恢复。

### 3. 在线主页与网易云排行榜

_即使还没有本地音乐，也能从在线推荐、公开歌单和排行榜开始听歌。_

- 本地曲库为空时提供在线发现内容，方便只使用在线音源的用户开始听歌。
- 主页支持切换可用音源，音源选择入口在未登录状态下也保持可用。
- 根据音源能力和登录状态展示推荐歌曲、推荐歌单或公开发现歌单。
- 未登录时可使用音源允许的公开发现入口；需要账号的内容仍按音源要求登录。
- 主页整合继续收听、最近播放和在线内容入口。
- 新增**网易云排行榜**展示，可打开榜单详情和歌曲列表。
- 榜单详情刷新实际曲目，减少长期复用旧歌单缓存导致的榜单过期。
- 排行榜与歌单加载提供空结果、失败和重试提示。
- 切换音源后及时清理旧来源的可操作内容，避免把旧歌单操作发送到新音源。
- 修复未选择歌曲时主页播放入口缺失的问题。
- 调整主页播放控制与内容区布局，清理重复操作入口。

### 4. 任务与通知中心

_后台正在做什么、哪些任务需要处理，都能在标题栏集中查看。_

- 标题栏新增统一的**“任务与通知”入口**，显示进行中的任务数和未读通知状态。
- 集中展示曲库扫描、元数据补全、响度分析、音源下载及应用更新。
- 提供“全部”“进行中”“需处理”筛选，方便查找正在执行或需要重试的任务。
- 显示任务阶段、已处理数量、进度和失败原因。
- 曲库扫描可按服务能力暂停、继续、取消与重试。
- 已校验的软件更新可从任务区域继续安装。
- 音源下载可取消；失败或已取消的任务可重新下载。
- 完成任务提供对应结果入口，减少在多个设置页和弹窗之间查找的步骤。
- 响度分析中的部分失败也会进入需要处理的结果范围。
- 通知保留当前应用会话的历史记录，可查看、标记已读和清空。
- 新增**勿扰模式**，抑制浮动提示，同时继续保留通知记录；勿扰偏好会保存。
- 保留通知中的撤销、重试等操作入口。
- 改进通知重复合并、操作状态和焦点管理。
- 使用键盘关闭任务与通知面板后，焦点返回打开面板的控件。

### 5. 下载完成后的后续操作

_下载完成后，可以接着播放、定位文件，或把它加入本地曲库。_

- 下载面板和任务中心的完成项可**直接播放下载文件**。
- 可打开文件所在目录。
- 可将曲库外的下载结果**加入本地曲库**，并区分已索引与等待索引的状态。
- 文件已位于授权曲库目录内时，重新索引该文件。
- 文件位于曲库外时，将其复制到已授权音乐库目录，保留原文件。
- 加入曲库时拒绝覆盖已有文件，并提供明确的失败提示。
- 同一下载结果的并发操作按顺序处理，减少重复复制和状态覆盖。
- 播放、定位和入库使用主进程记录的实际下载路径，并重新检查路径与目录授权。

### 6. 个人数据备份与迁移

_把歌单、队列、歌词修改和收听记录一起带走，恢复前先检查内容与冲突。_

设置中的“个人数据备份与迁移”可导出、预览和恢复以下十类数据：

| 数据类别   | 包含内容                         |
| ---------- | -------------------------------- |
| 曲库       | 曲库索引、音乐目录与已移除记录   |
| 歌单与收藏 | 应用歌单及收藏数据               |
| 队列工作区 | 命名队列与播放顺序历史           |
| 当前播放   | 已保存的播放队列、当前曲目和位置 |
| 歌词       | 歌词编辑及时间偏移               |
| 播放书签   | 保存的曲目位置                   |
| 电台       | 电台收藏                         |
| 播客       | 订阅和收听进度                   |
| 收听统计   | 日期记录与曲目累计统计           |
| 版本关系   | 歌曲与专辑的版本、来源关系       |

- 导入前展示备份时间、格式版本、记录数量和冲突数量。
- 可勾选需要恢复的数据类别。
- 冲突时可选择保留本机记录或采用备份记录。
- 支持**音乐目录映射**，方便迁移到另一台电脑或不同盘符。
- 路径映射在恢复确认后执行，选择目录时不会提前改变当前曲库配置。
- 同一歌单、队列会话和播客订阅按完整记录处理，避免片段式合并损坏结构。
- 当前播放快照和版本关系按完整文档处理。
- 统计按日期和曲目合并，重复导入不会把统计数值简单累加。
- 恢复安排在下次启动时执行，先保留原数据，再恢复选中的内容。
- 恢复过程中发生中断时保留日志，供下次启动继续处理。
- 增加导出、恢复失败和重复操作的状态反馈。

> [!IMPORTANT]
> **换机时，请另外复制音乐文件。** 个人数据备份不包含原始音频文件、账号登录信息、插件和封面缓存。设置与主题仍使用单独的设置备份入口；换机后需重新配置账号、音频设备和音乐文件位置。

### 7. 软件更新流程

_下载进度可见，中断后可继续；安装前会再次核对文件完整性。_

- 完善应用内的新版本检查、更新说明、下载、安装及升级结果确认。
- 支持稳定频道和测试频道，按版本号规则选择更新。
- 稳定频道排除预发布版本；只提示高于当前版本的更新。
- Windows 使用完整安装包升级，前端、Electron 和原生音频组件一同更新。
- 下载记录和更新偏好会保存，重启后可恢复候选更新或重新验证已下载安装包。
- 中断下载保留部分文件，后续下载在服务器支持时进行**断点续传**。
- 对续传响应检查起点和总大小，避免将错误响应拼接进安装包。
- 下载界面显示进度、速度和剩余时间估算。
- 加入连接超时、连续无数据超时及可恢复网络错误的有限重试。
- 下载完成后验证**文件大小和 SHA-256**，校验通过后才允许进入安装流程。
- 安装前再次校验已下载文件，避免使用已损坏或被替换的安装包。
- 取消下载后等待旧任务清理完成，再允许重新下载。
- 支持后台检查间隔、关闭自动检查、“明天提醒”和“跳过此版本”。
- 后台检查只提示新版本，下载和安装由用户主动决定。
- 安装前保存播放状态；保存或启动安装器失败时保留应用运行，方便重试。
- 再次启动后检查实际版本，区分升级完成与安装尚未完成。
- macOS／Linux 保留版本提示与发布页入口，不执行 Windows 安装流程。

### 8. 背景与界面材质编辑器

_在同一个编辑器里调整背景与材质，先预览，再决定是否保存。_

- 新增统一的“背景与界面材质”编辑入口。
- 可分别调整本地音乐、在线音乐、播放页与设置页的背景。
- 可配置页面继承全局背景，或使用独立背景。
- **深色与浅色方案**分别编辑和预览。
- 支持背景颜色和自定义图片。
- 提供背景模糊、亮度、遮罩、画面缩放及水平／垂直位置调节。
- 可根据背景选择文字色调，改善图片与透明背景上的可读性。
- 将跟随主题、透明、毛玻璃和液态玻璃材质整合到同一流程。
- 保留卡片外观和液态玻璃的进一步参数调节。
- 可在编辑器中切换预览页面，也可进入**全窗口预览**。
- 全窗口预览临时显示对应页面，返回后保留设置导航状态。
- 取消编辑恢复原偏好，保存后才提交配置。
- 修复液态玻璃覆盖页面壁纸、预览页面与实际背景不一致等问题。

### 9. 首次使用引导与快速配置

_按本地、在线或混合使用方式配置，完成前可以回看自己的选择。_

- 按本地音乐、在线音乐或混合使用方式展示适用的配置步骤。
- 欢迎页支持背景颜色及自定义图片的即时预览。
- 本地音乐步骤集中配置音乐目录、自动监听、BPM 分析和在线歌词回退。
- 在线音乐步骤配置音质与缓存，并可在完成后进入登录或插件市场。
- 播放器步骤配置底部播放栏和独立迷你播放器。
- 音频步骤集中处理输出设备、独占模式和试听。
- 新增**左右声道测试音**，便于检查当前设备、输出后端和音量是否正常。
- 试听使用独立服务，结束、取消或失败后清理临时音频与服务状态。
- 正在播放、静音或已有试听任务时提供对应限制和提示。
- 系统步骤集中配置窗口关闭方式、登录系统后启动、系统媒体控制、快捷键及恢复播放偏好。
- 完成页汇总当前选择，可返回已访问步骤修改，再回到总结页。
- 允许提前完成，只保存已经访问步骤中的选择。
- 未选择使用方式时直接跳过，不额外改写音频与系统集成偏好。
- 从设置重新打开引导时读取现有配置，保留用户已经保存的选择。
- 完成后可继续进入在线音乐、登录、插件市场或打开迷你播放器。
- 设置页增加**“快速配置”**，提供添加本地音乐、选择声音输出和调整主题的快捷入口。

## 功能与体验改进

_熟悉的页面继续完善：让设置更容易找，让曲库信息更完整，也让音频编辑更方便。_

### 10. 设置页重组

设置按用途整理为七个分类：**通用、外观、播放与音效、歌词、媒体库与存储、连接与控制、系统与关于**。

- 只显示当前分类，切换时保留其他分类的输入、编辑草稿和折叠状态。
- 关闭后重新打开设置，恢复上次分类。
- 基础选项与高级参数分组展示，提供可折叠区域和当前配置摘要。
- 条件不满足时说明不可用原因，减少看见开关却无法理解作用范围的情况。
- 设备档案、播放恢复、DSP、音量保护和交叉淡化等设置使用更准确的名称与说明。
- 将容易混淆的独立开关拆开，避免多个功能挤在同一行。
- 搜索结果先切换分类，再展开目标分组、滚动定位并聚焦控件。
- 保留旧设置入口的定位兼容，改进更新、下载、DSP、桌面歌词等目标的精确跳转。
- 设置侧栏在页面切换和长列表滚动时保持稳定。
- 预留滚动条空间，减少长短分类切换时内容宽度变化。
- 宽窗口提供侧栏导航，窄窗口使用分类选择菜单。
- 分类导航支持方向键、Home／End 和键盘焦点管理。
- 统一标签、说明、开关、滑条和操作按钮的对齐。
- 调整浅色、深色及透明材质下的文字与状态对比度。
- 减少悬停时的位移，保持设置控件位置稳定。
- 更明确地区分底部播放栏形态与独立迷你窗口。

### 11. 播放栏、标题栏与窗口布局

_调整封面、控制区和辅助工具的比例，改善不同窗口宽度与显示缩放下的布局。_

- 统一播放、暂停、上一首、下一首和其他常用图标的形状与尺寸。

### 启动与页面加载

- 后台任务和通知相关界面按需加载，减少启动包的即时加载工作。

- 统一控件和渲染逻辑，减少重复状态转换与不必要的页面工作。

### 大队列与曲库操作

- 队列授权在同一次请求内复用重复来源的检查，并限制并发数量。
- 队列内容未变化时复用原生已提交内容，手动选择歌曲主要更新当前游标。
- 曲目身份、顺序、CUE 范围或相关音频信息改变时重新验证内容。
- 减少队列快照中不必要的完整曲目复制和重复保存。
- 播放位置变化时复用队列总时长计算。
- 改进流媒体长列表的渐进加载和虚拟滚动覆盖。
- BPM 结果同时通过事件和请求回复到达时，减少重复回写和曲库重建。

### 歌词、频谱与封面

- 缓存歌词解析结果、静态行信息和时间轴，仅在对应内容变化时重新计算。
- 将长歌词时间轴中的重复扫描改为有界处理，减少大文本下的计算量。
- 动画主要处理当前视口附近的活动歌词。
- EQ 频谱、电平和播放栏可视化共享按需求启用的采样。
- 原生侧直接返回显示所需的频谱柱条，减少完整频谱的跨进程传输。
- 封面颜色缓存使用固定长度摘要，减少大图片字符串长期作为缓存键保留。
- 统一封面与颜色缓存清理，并隔离迟到的异步结果。

### 统计与持久化

- 收听统计改为异步数据库和脏记录增量提交，减少持续播放期间的全量同步序列化。
- 大批量导入分批处理，曲目记录和日期汇总共同提交。
- 旧统计成功迁移后才清理旧存储；迁移期间产生的新记录保留并重放。
- 保存失败保留待写记录并重试，避免将失败保存当成成功。
- 播放会话的不同保存入口共用调度，合并相同的待写快照。
- 改进周期保存预约，避免频繁播放更新让检查点不断推迟。

- 改进音频预算保护，能识别周期性超预算并进行退避或旁路。
- 复用不变的脉冲响应、重采样结果和 FFT 准备，减少无关 EQ 调整引发的重复卷积准备。
- 响度表使用固定容量统计，减少长时间处理中的历史节点分配。
- 修复 PCM 转 DSD 多声道缓冲步长与打包问题。
- 优化 PCM 转 DSD 的 FIR、环形历史和适用平台的 SIMD 计算。
- 减少音频回调中的首次扩容、中间复制和重复准备。
- 加强 WAV 容器签名识别，修复合法 WAV 被错误探测为其他格式的问题。
- 分析失败记录增加过期处理与容量限制。

</details>

### 液态玻璃与高 DPI 渲染

- 折射和高光贴图根据屏幕像素密度采用适用的采样精度。
- 为单张贴图尺寸、像素数量和缓存数量设置上限。
- 复用透明内区和直边计算，减少逐像素重复工作。
- 跨显示器 DPI 改变时更新贴图，即使 CSS 尺寸没有变化也能重新采样。
- 移除播放栏不再使用的边缘光照层及专用贴图生成。
- 减少重复裁切、持续 `will-change` 和不必要的合成工作。

> [!NOTE]
> 上述优化覆盖特定处理路径和回归场景，实际响应速度与音频稳定性仍取决于曲库规模、DSP 配置、声卡驱动和设备性能。

## Twilight AutoMix 自动混音

### 自然与 DJ 过渡

- 加入歌曲边界分析、原生过渡准备和播放协调基础设施。
- 分析节拍、速度、人声活动、能量及适用的歌曲交接位置。
- 提供**自然和 DJ 两类过渡策略**。
- 自然模式侧重保留歌曲内容；DJ 模式允许更长重叠、对拍及更明显的片头／片尾调整。
- 加入保持原速的非人声尾奏和尾音衰减交接策略。
- 对不适合混音、分析失败、准备超时或音源变化等情况回退常规播放，并提供状态原因。
- 连续专辑优先遵循无缝播放约束。
- 将来源身份、解码范围、过渡 PCM 和续播位置一起验证，减少混音结束后续播不一致。
- 加入可复用分析结果、分轨结果和容量限制。

### 分轨增强与计算设备

- 分轨增强可使用人声与贝斯等声部辅助安排交接。

- 加入**本地 ZIP 分轨包安装流程**，检查格式、模型版本、校验值、磁盘空间和实际运行环境。

- 提供安装后是否开启增强的选择，以及内存／显存占用提示。
- DJ 模式增加明确确认，说明可能跳过较多歌曲内容和产生长时间重叠。

> [!NOTE]
> 分轨运行包作为**独立附件**提供。分轨的 GPU 计算与播放器核心音频链路的 CUDA 加速是不同能力；本次正式包不承诺后者。

## 升级与使用说明

_升级前后建议留意以下数据范围与行为变化。_

- 可沿用已有音乐库和配置；首次启动会按需要迁移统计等数据。
- 升级前可导出现有设置；升级后可通过新增的个人数据备份功能保存歌单、队列、歌词编辑、统计和其他个人记录。
- 换机时请另外复制音乐文件；个人数据备份只迁移索引与记录。
- 更新功能需要安装包的 SHA-256 信息，请一并提供同名校验文件。
- 应用更新包支持续传；普通音源下载任务的历史仍限当前应用会话，没有新增跨重启下载任务恢复或暂停下载。
- 任务与通知记录以及播客取消订阅后的撤销操作以当前应用会话为范围。
- 统计日期及按日期清理使用 UTC 日；旧记录没有每日明细时，界面会说明不能按日期拆分的部分。
- **高／低搁架滤波现在会实际使用已保存的 Q 值**；使用此类 EQ 预设的用户可检查更新后的频响和听感。

## 别忘了：AutoMix 分轨包也在本次发布附件中

_想体验分轨增强，可以在下载播放器后，再按设备选择 GPU 等分轨运行包。_

**GPU 分轨包文件：** `TwilightEcho-AutoMix-Stems-GPU-Windows-x64-1.3.0.zip`。对应的 SHA-256 校验文件以 `.zip.sha256` 结尾，可与运行包一并下载。

> [!IMPORTANT]
> **播放器安装包与分轨运行包需要分别下载。** GPU 等分轨包会与本次 Release 一起提供，请在发布页下方的 **Assets（附件）** 中查看。基础 AutoMix 可以直接开启；需要人声、贝斯等分轨辅助时，再安装对应运行包。

1. 在本次 Release 的附件中下载适用于自己设备的**分轨 ZIP 包**。
2. 打开 **设置 → 播放与音效 → 歌曲衔接 → Twilight AutoMix**，点击 **“安装分轨包…”**，选择下载的 ZIP 文件。
3. 等待格式、校验值、磁盘空间和运行环境检查完成，再按需要开启**分轨增强**。
4. 计算设备可选择**自动、GPU 或 CPU**，具体可用选项以软件检测结果为准。“自动”优先尝试可用 GPU，并在适用的显存失败场景回退 CPU。

> [!TIP]
> 分轨增强会占用额外内存或显存。可以先用“自然”模式与“自动”计算设备试听；选择 DJ 模式时，请留意确认提示中的歌曲内容跳过与长时间重叠说明。
