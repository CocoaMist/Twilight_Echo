# Twilight Echo 1.4.0-perview

2026-10-26 · Windows x64 预览版

## 主要变化

- **音频与 DSP**：扩展重采样相位、目标采样率策略和 DSD512 调制；补充回调负载、削波统计、响度范围、静音边界与 2000 点波形分析。
- **音频工作台**：重整 DSP 信号链、输出设置、场景监测和均衡器控件，播放进度支持分析波形。
- **外观与歌词**：改进图层检查、窗口预览、主题编辑与歌词字号布局。
- **音乐资料**：新增公共资料源、艺术家与录音交叉核验、专辑子集识别和 NCM 文件身份读取；保留原有手工资料及授权读取方式。
- **音乐库**：加入艺术家详情、资料管理和曲库健康诊断；完善后台刷新、首次导入和个人资料备份恢复。
- **搜索与存储**：引入相关性排序与拼写纠错；SQLite schema 29 支持旧文件发布日期的窄回填、成功发布和取消／恢复围栏。
- **安全更新**：Electron 更新至 43.8.1，修复相关权限归属与证书问题；同步升级 undici、ip-address 和 body-parser 的安全修复版本。

## 已完成的验证

- Windows x64 安装包生成、版本与原生依赖检查通过，包内主界面已检查。
- 包内首启／冷启动、一次性迁移、原生播放、无窗口持续播放、两次窗口重建与正常退出测试通过；重建没有重复发送播放指令，冷启动保留暂停位置。
- Electron 43.8.1 运行时与包内验证通过，生产依赖安全审计没有中／高／严重级别的未处理公告；冻结依赖安装、既有安全补丁和 NCM 兼容性检查通过。
- Node／Web 类型检查、完整仓库 ESLint（0 错误、7 项既有夹具警告）、生产构建与渲染资源预算通过；原生测试 49 项通过、1 项跳过，新构建响度分析测试 5 项通过。

## 仍待完成的验收

- 十万曲库的 Catalog／Genre／Focus 仍有秒级热点，M5.3 性能尚未通过。详见 [实测记录](../unified-music-library-m5.3.md)。
- 完整自动回归尚未全通过：部分既有测试合同／夹具需要更新，开发态 Electron 界面测试出现进程启动和目录访问失败。键盘、主题与完整安装／卸载流程仍待验收。
- ASIO 跨 DLL 测试缺少夹具而跳过；真实音频设备与独占输出仍需实机验证。

Windows 安装包按项目现有策略不签名，系统可能显示 SmartScreen 提示；安装包同时提供 `.sha256` 校验文件。
