# 设置页可理解性审查

审查基线：`d6737208`。覆盖设置页九个分区、内置子编辑器和条件显示的控件，包括设备档案、独立迷你窗口、更新偏好、备份恢复和插件表单入口。检查名称是否对应实际行为、控制是否独立、说明是否给出作用范围、前置条件、保存方式和重启要求，以及键盘操作、搜索定位、浅色和深色阅读。

第三方插件的字段和主题插件自定义控件由插件提供；本次检查宿主的呈现和保存提示，不替插件改写业务含义。未改变保存字段、默认值、数值范围、播放器引擎或备份格式。

## 已定位并修复的问题

| 原有问题 | 调整 |
| --- | --- |
| “耳机护耳模式”实际启用交叉馈送，不能保证听力安全 | 改为耳机交叉馈送，说明混合声道；快捷方案明确关闭 EQ、强度 40% |
| “动态增强”实际只启用当前 EQ，没有动态压缩预设 | 改为使用当前均衡器，说明会关闭交叉馈送 |
| 音量与削波保护在同一行，无缝与交叉淡化也共用一行 | 拆成四个独立设置，淡化参数按名称分行，0 秒时禁用曲线和内容规则 |
| DSP 主开关关闭时，CSS 屏蔽鼠标，但键盘仍可启用子模块 | 允许操作本来就会自动开启 DSP 的模块，并显示这个行为 |
| 播放条与独立浮窗都叫“迷你” | 底部播放条改称细长，独立窗口明确称独立迷你窗口 |
| 恢复播放易被理解为启动后自动播放 | 改为记住上次播放，保留“需手动播放”的说明 |
| 开机启动实际发生在账户登录之后 | 改为登录系统后启动 |
| 下载命名示例总显示 `.m4a`，但实际格式由音源决定 | 展示名称示例，说明后缀由音源决定 |
| “重置库”“清除”“外观/播放/桌面歌词”按钮看不出作用范围 | 改为清空媒体库索引、跟随扫描文件夹、恢复某分组默认；保留确认与数据保护 |
| 首次尚未取得文件夹监听状态时显示失败 | 显示状态尚未获取，避免推断监听失败 |
| 单独玻璃开关与全局开关关系不明 | 说明关闭全局仍可能保留独立区域的效果，覆盖选项使用具体区域名称 |
| 设置搜索找到折叠选项后只跳到分区，子项未出现 | 请求打开相应本地折叠状态，再测量、滚动并高亮；支持原生 details |
| 相似标题可能命中父项，例如背景模糊与暗化 | 设置标题优先精确匹配；同步过时的桌面歌词索引与实际控件标签 |
| 条件控件被隐藏时没有解释 | 搜索定位到前置开关并提示；搜索本身不修改保存值或启用前置功能 |
| 部分开关是不可聚焦的 span，没有键盘激活或名称 | 使用有名称的原生按钮和禁用属性，保留既有事件处理 |
| 说明文字小、对比偏低，大量英文与实现术语增加阅读负担 | 说明字级从 12 调为随正文缩放的 13，适度增强对比；高级格式参数折叠、采用中文名称与单位 |
| 主题工坊入口使用缺少本地样式的按钮，两种模式都出现默认浏览器外观 | 复用设置页现有按钮样式，保持禁用状态与相邻操作一致 |
| 深色关闭开关的轨道与圆钮几乎融入背景，容易误判为不可用 | 设置页增强关闭轨道和圆钮对比；禁用透明度独立保留 |

## 验证

Windows 原生 Electron 实机通过 Computer Use 检查九个导航入口、两种明暗模式、折叠设置的搜索与禁用状态。使用独立测试曲库和用户目录。

设置滚动回归使用真实 SettingsPage 和 SettingsDisclosure，验证初始不渲染的子面板、重复搜索重开、前置条件定位、原生 details 展开、窄窗口导航、输入与折叠状态保留、平滑滚动中断和卸载清理。主题与应用测试、类型检查、构建和现有资源预算另行执行。

设置索引单独输出为构建块，避免新文案把主应用块推过已有预算；未放宽预算。第三方插件、真实账户权限和所有物理声卡的组合不属于本次文案/交互运行证明。
