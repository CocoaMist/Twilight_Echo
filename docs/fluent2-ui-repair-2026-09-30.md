# Echora Fluent 2 界面修复记录

本轮将主仓库的导航、排版、反馈、确认流程和窗口适配统一到同一套 Fluent 2 规则，并修复评估中发现的主要交互问题。菜单不再退出当前页面，浏览均衡器类型不会改变声音，工具页保留播放控制，未保存主题受到保护。

这份记录对应实际源码改动。上一份[全界面评估与统一 HIG 方案](ui-hig-unification-plan-2026-09-30.md)保留原始意见和评估证据。这里区分已实施的修复、尚保留的产品差异，以及未完成的实机验收。

## 依据与范围

规则来源是微软 [Fluent 2](https://fluent2.microsoft.design/) 官方手册，包括用户指定的 [Layout](https://fluent2.microsoft.design/layout)，以及 Typography、Nav、Dialog、Button、Drawer、Field、Tab list、Toast、Message bar、Shapes 和 Iconography。阅读快照保存在工作区的 `research/fluent2-repair-20260930/fluent-*.txt`，供实现与后续审查追溯。

实现仍使用现有 Vue 和 Electron 架构。公共 HIG 层覆盖主界面及三个卫星窗口，音乐封面、歌词内容、专业音频图形保留各自的内容表达。这里不把 Fluent React 组件示例视为必须迁移技术栈的要求，也不把一次构建称为所有设备上的视觉验收。

基线是主仓库 `main`、HEAD `344fb03`、package 版本 `1.2.1`，包括本轮开始时已有的工作区修改。开始前已保存源码基线与原有差异；版本号未更改，没有提交、推送或制作安装包。原有逻辑检查的主进程改动未被回退。

## Echora HIG 的固定规则

### 布局与导航

间距以 4 像素为基础，常用 8、12、16、20、24、32。页面边距通常为 24，宽屏可用 32，紧凑窗口为 16。按钮和表单控件使用 4 像素圆角，内容面板与弹窗通常使用 8，主导航贴边时不使用悬浮胶囊轮廓。

全局导航宽度为 260，保持文字标签及一级嵌套。音乐库展开歌曲、艺术家、专辑、流派、歌单、聚合歌单和文件夹；平台内容导航属于当前页面的浏览范围。选中状态、展开状态和实际目的地分别表达。

响应式判断使用窗口可用 CSS 像素，与 Windows 的逻辑像素对应，不能只根据显示器标称分辨率选择布局。Fluent 手册提供 320、480、640、1024、1366、1920 等断点参考；本产品采用以下适配选择：

| 条件               | 行为                                                         |
| ------------------ | ------------------------------------------------------------ |
| 宽度不足 1024      | 全局导航成为临时覆盖面板，背景不可操作，选择目的地后收起。   |
| 宽度为 1024 或更大 | 默认展示全局导航；菜单仍可主动收起。                         |
| 宽度不大于 1440    | 设置使用搜索和分区选择器；主题及声音工作台减少同时展示的列。 |
| 宽度不足 640       | 专业工作台改为纵向主区，次级内容顺序展开。                   |
| 高度不大于 800     | 首页缩小封面与间距，减少首屏装饰占用。                       |
| 工具页有当前曲目   | 固定紧凑传输控制，并为内容预留底部空间。                     |

1024 的导航阈值和 1440 的工具阈值是基于音乐工作台内容宽度的产品选择，不是将它们伪称为 Fluent 的唯一规定。主窗口现有最小尺寸仍为 760×692；低于此尺寸的浏览器样本不能替代原生最小窗口验收。

### 字体与图标

界面默认采用系统字体栈，Windows 优先 Segoe UI Variable 和 Segoe UI，中文使用系统可用字体回退。正文 14/20、辅助文字 12/16、较大正文 16/22、区块标题 20/26、页面标题 28/36，常用标题字重为 600。歌词内容字号独立，不允许它改变工具栏、导航或表单的字体。

“跟随主题字体”是明确的用户选择，不再混入“系统字体”的含义。新默认小窗配置继承主界面；既有独立字体、歌词配色和个人主题保留，避免把升级当作重置用户偏好。

公共图标取自官方 `@fluentui/svg-icons` 1.1.343，使用 20 像素 regular SVG 和当前文字颜色。选取资源、来源记录和 MIT 许可保存在 `src/renderer/src/assets/fluent-icons/`。遗留图标类通过公共映射逐步迁移；装饰图标不进入按钮的可访问名称。

### 提示与确认

| 信息类型                                 | 呈现方式                                                    |
| ---------------------------------------- | ----------------------------------------------------------- |
| 与当前页面相关的加载失败或需要处理的问题 | 页面 MessageBar，错误与警告使用 alert；必要时提供重试动作。 |
| 操作已完成、普通短消息                   | 全局通知，默认七秒，最多四条，信息使用 status。             |
| 重要错误或需要用户动作                   | 持续通知，手动关闭，并能在本次会话的通知记录中找回。        |
| 字段无效                                 | 字段标签和明确验证状态；不能只靠短时通知。                  |
| 删除、重置、卸载或放弃草稿               | 具有明确作用范围、动作名称和取消入口的确认弹窗。            |

确认弹窗按序显示，禁止取消被解释成确认。普通弹窗支持 Esc 和背景关闭；破坏性确认必须通过底部按钮选择，避免误触。文字输入初始聚焦输入框，破坏性确认初始聚焦取消；Tab 和 Shift+Tab 不离开当前弹窗。弹窗叠在旧弹窗或抽屉上时，底层表面也会禁用，关闭后恢复原焦点与背景状态。

扩展中心的快速卸载保留插件数据，设置面板中需要清除登录状态和配置时有明确的额外选择。此文档只描述产品行为，本轮没有实际卸载用户插件或清除缓存。

### 主题与窗口

主题负责允许范围内的颜色、材质和内容外观。全局导航的宽度、标签、宿主操作位置以及工具页播放控制不再由主题随意隐藏或挪动。既有主题布局字段仍保存在文件中，支持兼容和导出，但宿主 HIG 优先。

主题预览使用实际本地首页组件。离开编辑器或选择另一主题时，未应用的草稿必须被明确处理。切换浏览、菜单展开、返回来源页面不会顺带改变音频配置。

主播放页、迷你播放器、桌面歌词和托盘继续使用同一播放与歌词会话。字体和主题继承的默认规则已统一；独立歌词配色、单行双行、竖排等属于内容能力，予以保留。

## 仍需手动验收的内容

真实网易云播放需要人工确认声音正常，再检查暂停、定位、切曲以及进入声音工作台后持续可控。本轮不把此前进度推进等同于已经听到正常声音。

QQ 登录问题仍属外部 Provider 的待诊断项。本轮修复准备态超时、取消和过期响应处理，没有证明 QQ 登录根因已解决，也没有用网易云登录结果替代 QQ 的验证。

应在实际窗口检查 100%、125%、150%、200% 系统缩放，以及混合 DPI 多显示器移动；分别验证主窗口最小尺寸、常见笔记本窗口和较宽显示器。任务栏歌词、锁定穿透的解锁、迷你播放器三种布局和独立字体也需要在原生窗口复核。

剩余整理包括主题外观域的进一步合并、旧业务组件的逐步迁移、专业节点文案和剩余遗留图标。已建立的公共 HIG 层与行为契约为这些调整提供边界，本轮没有删除兼容数据或压缩掉专业音频功能。

## 维护与恢复

公共规则位于 `assets/fluent.css`，反馈和弹窗位于 `components/hig/`，导航与确认规则位于 `app/useAppNavigation.ts`、`useNavigationGuard.ts` 和 `useAppDialog.ts`。新增页面应先复用这些规则，避免再次定义独立的全局导航、确认框或字体语义。

本轮开始时的基线保存在 `research/fluent2-repair-20260930/baseline/`，原有工作区差异另存为 `preexisting-work.patch`。恢复必须逐文件比对，不得使用全仓库重置来覆盖另一个对话的改动。隔离用户目录包含私人登录状态，不纳入公共文档、提交或证据导出。
