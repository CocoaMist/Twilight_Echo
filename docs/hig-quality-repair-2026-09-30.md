# Echora Apple Music / Fluent 2 质检修复记录

本轮已落实[界面质检报告](./ui-quality-review-apple-music-fluent2-2026-09-30.md)中的 Q1–Q9，并统一队列与搜索范围的表达。公共布局、交互与反馈沿用 Fluent 2，音乐库、待播内容和小窗衔接参考 Apple Music Windows 用户指南。

源码修复、组件行为检查、类型检查、静态检查和页面构建已完成。最终真实窗口的视觉、系统缩放和声音验收仍待完成，不能把本记录理解为所有页面实机验收通过。

## 本轮变更

| 对应问题              | 已落地的行为                                                                                                                                                                                                                                                                                             |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Q1 小窗标题覆盖       | 公共标题与标题字体规则限定到主窗口，迷你播放器、托盘播放器和桌面歌词保留各自的排版角色。紧凑小窗标题恢复 13px，独立字体能够继承到标题。                                                                                                                                                                  |
| Q2 紧凑主题预览不可达 | 1440px 及以下提供“编辑／预览”页签；宽窗口同时展示两区。切换使用同一份草稿，不卸载编辑区，保留字段和滚动状态。                                                                                                                                                                                            |
| Q3 核心键盘操作缺失   | 歌曲行支持上下方向键、Home/End、Enter 播放、空格选择、Shift＋方向键范围选择、Shift＋F10 菜单。跳到远处曲目时先更新虚拟列表再移交焦点。隐藏页面停用多选快捷键。DSP 节点支持键盘选择、独立编辑按钮及 Alt＋上下方向键排序。播放浮层关闭按钮支持键盘激活。                                                   |
| Q4 首页预览不准确     | 主题预览改用与主界面相同的 LocalHome 分派，展示当前主题对应的真实首页结构，保留预览的 inert 边界。                                                                                                                                                                                                       |
| Q5 进度名称不统一     | 标准播放栏补充“播放进度”可访问名称，与紧凑和迷你形态一致。                                                                                                                                                                                                                                               |
| Q6 页签契约不完整     | EQ、在线搜索、电台／播客、网络源和主题工作区补齐单一 Tab 焦点、选中状态、面板关联和方向键／Home／End。不可用搜索类型会被跳过。浏览 EQ 类型继续只改变显示；应用声音模式仍需明确操作。网络源切换页签会结束目录浏览，避免页签与内容不一致。                                                                 |
| Q7 错误缺少恢复入口   | 公共提示默认可关闭；内容或意图变化时重新显示。导入、推荐、网络目录、插件、电台／播客、主题及 DSP 失败增加对应恢复操作。登录失败使用同一提示栏，并保留重试和返回。整页失败保留可见的恢复入口。电台“检查输入”定位到具体表单，导入、目录和播客输入关联错误说明。成功消息使用 status，错误／警告使用 alert。 |
| Q8 小字可读性         | 迷你播放器及其设置面板的 9–11px UI 信息提高到 12px，并调整信息区高度；歌词的独立内容排版保持自身规则。                                                                                                                                                                                                   |
| Q9 歌词配色浮层       | 打开时聚焦当前配色；方向键与 Home/End 移动选项；Escape、外部点击和焦点离开能够关闭。选择或 Escape 后焦点返回触发按钮，卸载时移除监听。                                                                                                                                                                   |

播客订阅列表补充了真正的选择按钮，可以用键盘切换订阅，取消订阅保持独立操作。

## 播放与搜索衔接

- 临时待播内容统一称为“播放队列”，保存的集合称为“歌单”。本地与在线曲目菜单增加“加入队尾”，批量选择复用既有批量队列接口。
- 迷你播放器的队列位置成为队列入口，先保存小窗设置，再返回主窗口打开队列。主窗口异步挂载播放栏后继续完成打开操作；没有播放内容时入口禁用。
- 本地列表与在线搜索复用“搜索范围”控件，统一“当前音乐库／全部来源／平台名称”。切换范围沿用已有查询和关键词状态。
- 在线搜索删除旧自定义来源菜单及多层叠加样式，采用原生选择控件和同一套页签样式。现有外观变体通过公共操作契约保持导航、队列、提示和焦点行为一致。

## 保全与验收边界

本轮不使用 Computer Use，没有操控用户的浏览器或应用窗口。隐藏组件测试使用独立临时配置，未读取真实登录凭据。修复前保存了源码快照、既有差异和 package.json；另一对话涉及的 9 个音频／插件主进程文件与本轮基线逐字节一致。版本保持 1.2.1。

证据保存在 `research/hig-quality-repair-20260930/`，包括修复前快照、变更列表、各项日志、独立构建及 `verification-summary.json`。前两轮评估和修复文档保留为历史记录。

待实机验收：迷你播放器三种布局在实际小窗尺寸下的文字裁切；所有页面的短窗口、长名称、深浅主题和 125%–200% 系统缩放；桌面歌词锁定、拖动、点击穿透及焦点行为；网易云真实出声、切曲和队列衔接。QQ 登录问题保留未验证状态。
