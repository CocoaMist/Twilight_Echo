# 窗口与按钮视觉一致性修复

本轮从右上角按钮不协调的问题扩展检查主窗口、迷你播放器、桌面歌词、托盘播放器及弹窗。35px 标题栏是本项目根据用户要求采用的尺寸；不同用途的控件保留不同尺寸，但同一组控件共享尺寸、图标规格与状态规则。

## 已修复的共性问题

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 右上角图标大小、粗细不同 | 字体铃铛、不同画布的 SVG 和字体关闭图标混用 | 四个按钮统一 46×35px，使用同一 12px SVG 图标画布与线宽，缩小并对齐通知标记 |
| 切换主题后按钮变形或错位 | 旧主题修改标题栏最小高度、按钮圆角与位移 | 全局标题栏固定 35px；窗口按钮、左侧命令按钮不受旧布局规则移动 |
| 左侧菜单、设置、扩展图标不统一 | 自绘 SVG、字体图标和单独拼图图标混用 | 使用同一套 20px Fluent 命令图标 |
| 小窗口图标有大有小 | Fluent 映射固定 20px，其他图标沿用 12～17px 字号 | 图标映射按控件的尺寸变量缩放；迷你工具、自定义关闭、桌面歌词为 16px，托盘图标为 18px |
| 弹窗图标没有采用统一样式 | 图标规则限定在 `#app`，Teleport 弹窗位于其外 | 图标规则覆盖应用文档中的弹窗，统一提示和弹窗关闭按钮 |
| 托盘按钮悬停出现焦点框 | 悬停与键盘焦点共用样式 | 悬停仅改变背景，键盘焦点保留明确边框 |
| 桌面歌词工具栏忽略字体设置 | 后面的 `font` 简写覆盖前面的字体声明 | 工具栏完整使用配置的界面字体及统一行高 |
| 导入标题挤在关闭按钮旁 | 旧组件的 `flex-end` 和内边距覆盖统一布局 | 标题靠左、关闭靠右，24px 内边距；底部使用共享按钮，移除旧渐变、发光和圆角按钮样式 |

## 验证

- 最终应用回归：369 项通过，无失败。
- 相关控件与小窗口回归：18 项通过；新增导入弹窗实际布局检查也通过。
- 类型检查、修改组件的代码检查及独立构建通过。
- 实际组件加载 Fluent 图标样式，并检查 Teleport 弹窗，避免只在缺少图标样式的测试页面中验证尺寸。
- 组件布局覆盖 760、1024、1280、1920、2560、3840px 宽度；检查深色与浅色旧主题不能撑高标题栏或改变按钮几何。
- 原生窗口复查：主标题栏、通知面板、导入弹窗、在线音乐页、迷你播放器工具栏、自定义关闭与返回主窗口、桌面歌词工具栏与关闭。网易云曲目保持暂停后进行小窗口操作；最终构建确认导入标题靠左、关闭靠右、操作按钮使用共享样式。
- 托盘播放器本轮验证了真实组件的图标布局与样式，未通过系统托盘入口进行原生操作。

所有预览和验证使用独立测试配置与输出目录。没有改动版本号、发布目录、真实用户音乐库或另一轮检查负责的音频与插件主进程逻辑。

设计依据延续 [Fluent 2 Layout](https://fluent2.microsoft.design/layout) 的层级与一致性原则；播放主操作保留音乐播放器所需的明确视觉层级。
