# 外部歌单导入

在应用歌单页选择“导入外部歌单”，粘贴分享链接或从磁盘选择文件。导入歌单保留来源信息、原始顺序、重复歌曲和不可用条目；文件读取完成后即可查看所有歌曲，平台读取期间会逐页显示已读条目，并在最后一页到达前保留“不完整”状态。

内置解析器支持 M3U、M3U8、PLS、XSPF、静态 WPL、ASX/WAX、KGL、Apple Music/iTunes XML、带表头的 CSV/TSV，以及“艺术家 - 歌名”纯文本。单文件上限为 8 MiB、每份歌单上限为 20,000 条。XSPF 多个 `location` 是同一首歌曲的备选地址；HLS 直播媒体清单、动态 WPL 查询、带自定义 DTD 的 XML 和嵌套 ASX 播放清单会拒绝导入。酷狗 KGL 变体不一致时，先另存为标准 M3U8 或 CSV。

酷狗 FPL/FPLite 继续使用“歌单文件桥接”插件；foobar2000 可导出 M3U8。相对文件位置按歌单文件目录解析。自动补全仅关联本地音频或启用音源中的稳定歌曲标识，不下载音乐、不保存临时播放地址；播放地址只在开始播放时请求。

直接读取能力：网易云通过已启用的内置音源分页读取；`163cn.tv` 短链只跟随 HTTPS 跳转到网易云官方歌单域名。QQ 接受 `i2.y.qq.com` 分享页。酷狗 `gcid_...` 分享歌单需要酷狗音源声明完整读取能力；旧版公开接口只支持数字 `specialid`，不能把 GCID 当成数字 ID 请求。QQ、酷狗、酷我、Bilibili 公开收藏夹、YouTube Music、Spotify、Apple Music、TIDAL 与 Deezer 由对应的官方域名或已声明完整读取方法的音源读取。Apple Music 需要开发者令牌，读取私人资料库还需 Music User Token；Spotify 需要当前 API 接受的用户令牌和本人或协作歌单访问权限；TIDAL 与 YouTube Music 需要 OAuth 令牌。

汽水暂不具有内置的完整歌单读取实现；TIDAL 可通过官方 API 读取，但需要具备歌单读取权限的 OAuth 令牌。登录、区域和 API 配额也可能限制已接入平台。应用会保留部分读取进度并给出原因，可改用平台支持的 XML、CSV/TXT、KGL、M3U8 文件导入。不会自动切换至第三方代理。要让第三方音源提供完整读取，插件可实现可选的 `readPlaylistImportPage(playlistId, offset, limit)` 并在 `supportedMethods` 中声明；结果必须保留每个原始歌曲出现次数、确切总数和分页位置。

没有权限或网络失败不等于歌曲不存在。手动选源或稍后重新匹配可以重试；多版本候选保留待确认状态。手动更新会先读完整首屏/所有分页再显示新增、删除和顺序变化，保留匹配条目的手动绑定；有本地成员编辑时默认另存副本。令牌在当前读取窗口中传递，不写入歌单或设置；应用不会帮用户创建第三方开发者凭证。
