# TwilightEcho 代码精简、性能与交互收敛

比较基线：上游 main `6d11721`。性能优化比较基线：已提交的前一轮 `4af3094f`。本 PR 保留原功能和持久化契约；总量统计包括新增模块、基准、测试、文档与依赖文件，移动代码不当作净删除。

## 当前结果

整个 PR 净减少 **252 行**；其中应用实现、声明和工具脚本净减少 **1291 行**，已计入可复测基准脚本。测试与其他文件的净变化分别计入整体数字。

- 歌单命令、状态和曲目解析，以及 A–B 循环、投送、BPM 分析从巨型 Store 中分离。BPM/响度任务与缓存共用生命周期、并发去重、取消、回滚和版本 1 存储，保留各自的键与结果校验。
- 合并播放恢复校验、音频输出归一化、GB18030 检测、HTTP URL 校验、XML 转义、流式文件哈希和四套 Windows 工具链注册表恢复逻辑。字体目录只启动一个查询进程，并保留失败重试、清空代次与 Unicode 处理。
- 从实际实现推导 Store 返回类型，复用同构 preload DTO 和设置快照。Settings/Theme/AppNotice 的 44/26/5 个公开成员双向类型兼容，编译后 JavaScript 相同；有引用语义差异的键盘、小播放器、托盘声明仍保留原契约。
- 删除没有生产调用者的旧同步目录扫描/过滤代码。现行扫描由 `libraryScanService`、`scanPlanner` 和 coordinator 的排除及提交约束负责；相应现用扫描安全测试保留。
- 集合/专辑排序复用 `Intl.Collator`；日期排序每个集合只计算一次。扫描收尾用 Map 保留首个原始路径与插入顺序，删除重复 Set/Array，去掉平方级查找。版本化保存复用既有安全 value 写入，避免再次解析刚序列化的 JSON。曲库新增只建立一次排除集合并执行一次去重。
- 移除玻璃卡片和播放器的两套逐帧按压弹簧，以及与其竞争的全局/卡片缩放；短暂明暗反馈仅作用于最内层交互控件。定位 transform、disabled、键盘焦点、reduced/off 模式保留。删除仅验证已移除弹簧实现的测试入口，新增真实 Chromium CSS 状态检查。
