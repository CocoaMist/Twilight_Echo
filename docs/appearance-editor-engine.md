# 外观工作区

点击标题栏的「外观」按钮进入主题选择；「自定义当前主题」进入日常调整，主题选项中可进入主题制作和主题插件工坊。

「设置 → 外观」保留原来的主题、背景、字体和播放器设置及搜索定位，并增加「打开新版外观」入口。新版工作区从设置页进入时，返回仍回到原外观设置；原主题制作和工坊入口也可打开新版中的对应页面。

## PR #154 的移植范围

本次从 PR #154 选择性移入外观工作区及其必要依赖：

- 内置、个人和插件主题选择，以及主题目录的搜索、同步、安装与管理。
- 内框背景、外框、控件、侧栏、标题栏、播放栏、卡片、字体和图标设置。
- 日常调整、主题制作、插件工坊；2D/3D 预览、相机、图层及属性工具。
- 草稿历史、应用/放弃、恢复、图片资源、主题归档和持久化。

保留当前分支的 HiFi、队列、歌词管理、投送、书签、前进/后退、DSP 和发布流程；不移入 PR 的独立 DSP 窗口、侧栏把手及其他页面重设计。预览使用当前标题栏、侧栏和播放栏组件。默认材质不额外给全局按钮加阴影。

另按追加要求移入以下不改变页面布局的体验改进：

- 列表的 Ctrl/Cmd+A、Escape 只作用于当前焦点所在列表，输入框、菜单与弹窗优先。
- 歌曲行支持 Enter 播放、Space 选择；聚合歌单仅启用 Enter。嵌套按钮保留原生键盘行为，按住键不重复触发。
- 艺术家、专辑的现有 A–Z 索引支持中文拼音首字母。
- 网格过滤或删除后，虚拟窗口会夹紧旧的深滚动位置，避免剩余卡片空白。
- 自动滚动条只在状态变化时更新 class；指针离开或窗口失焦时取消待处理帧。
- 插件歌单搜索按声明的方法注册，支持取消请求，并在插件能力变化后更新。
- [默认音乐封面](default-music-cover.md) 使用 PR 的明暗两版，保留显式占位与真实封面的优先级。

队列历史重播与来源导航依赖 PR 的新队列界面和来源数据合同，未整套移入；当前分支已有的队列轻量快照专辑字段继续保留。列表尺寸、卡片布局与行高不跟随 PR 改版。

## 草稿与导航

日常设置、个人主题和插件项目各自保存，不因切换明暗、选择对象或旋转相机而提交。应用后修改进入对应设置或主题；放弃后恢复已确认外观。个人主题图层不会覆盖其他主题或全局图层。

打开设置、插件或音频工具时，外观组件保留在 overlay history 中并暂停；返回后继续原工作区。Ctrl+K 页面/歌单、侧栏和菜单等会丢弃工作区的操作统一经过 `app/appearanceNavigationGuard.ts`，等待当前编辑器的离开决定。工作区内切换主题、模式或搜索目标由 `AppearancePage.vue` 自己保护。

旧 `theme` 会话和旧工坊插件页面会迁移到新入口；原设置页的外观会话仍恢复到设置页。普通页面的同步导航和前进历史保持原合同。

整窗预览使用 `previewAppearance()` 发布临时 chrome 与 `appearanceLayers`，App 在预览期间挂载真实 `AppearanceLayersHost`。退出预览会撤销覆盖；正式设置直到显式应用才改变。

## 从部件打开完整属性

底部工具栏的部件顺序与画布占比保持不变。「调节」保留常用属性，「更多设置」在浮动面板中按组展开原有参数，不挂载旧设置页的整套布局。

- 内框背景提供页面继承、图片位置与缩放、文字明暗及通透推荐；主题背景样式和图片绑定进入主题草稿。
- 外框接系统窗口透明，保留系统支持条件与重启说明。播放栏接显示、播放页差异、自动隐藏、按钮编排、频谱和迷你播放器；卡片接完整卡片与玻璃参数。
- 文字与配色接系统字体、渲染、深浅色、强调色与封面取色。对应主题链接接字体文件、歌词、图标、导航、媒体库、播放页、均衡器、定时时段及可读性。
- 主题选项保留所有主题分类、名称、历史版本、复制、导入导出，并提供密度与动画等其他外观设置；主题插件工坊仍是独立入口。

播放栏、卡片、玻璃和深浅色偏好与常用属性共用日常草稿，支持应用、放弃和撤销重做。标注「立即生效」的字体、系统窗口效果、强调色、密度、动画及迷你播放器继续按原方式保存。主题参数沿用主题草稿；跨编辑器先确认未保存修改，保存失败保留草稿并显示错误。

`appearanceSettingsTargets.ts` 统一设置搜索与属性入口的部件、分组和参数定位。搜索会展开完整折叠链；条件未满足时定位启用开关，不把焦点送到隐藏参数。旧组件的草稿绑定均可选，原设置页仍保留即时保存方式。移除壁纸或改用纯色时会清除图片专用的透明搭配与文字明暗，恢复默认背景的原有行为。

## 代码边界

| 模块                                                          | 责任                                     |
| ------------------------------------------------------------- | ---------------------------------------- |
| `components/AppearancePage.vue`                               | 主题选择、编辑模式、离开保护及标题栏工具 |
| `components/settings-page/AppearanceSettingsSection.vue`      | 原设置页外观表单与新版工作区入口         |
| `components/settings-page/AppearanceWorkspaceSection.vue`     | 新版工作区的日常调整与属性面板           |
| `components/AppearanceWindowPreview.vue`                      | 草稿同步、隔离场景、相机和命中区域       |
| `components/AppearancePreviewScene.vue`                       | 真实组件与固定本地示例，不读取个人音乐库 |
| `editor/viewportGeometry.ts`、`createEditorViewport.ts`       | 几何、适配、缩放、平移与暂停             |
| `editor/appearanceLayerView.ts`                               | 3D 静态副本、材质取样与投影              |
| `editor/createEditorTransition.ts`、`createEditorParallax.ts` | 可中断过渡、有限入场与指针视差           |
| `components/AppearanceSurfaceInspector.vue`                   | 部件属性、颜色、材质和皮肤               |
| `components/theme-studio/`、`components/theme-workshop/`      | 主题草稿与插件项目、恢复和导入导出       |
| `app/appearanceLayersRuntime.ts`、`componentMaterials.ts`     | 正式窗口与预览共用的分层绘制             |
| `shared/appearanceLayers.ts`、`shared/theme.ts`               | 规范化数据、主题素材和图标绑定           |

引擎接收节点边界和视口，不读取 Vue、歌曲或主题存储。扩展对象时在 `appearanceParts.ts` 中注册部件与选择器，属性仍沿既有草稿和主题契约保存。

预览按源窗口 1:1 排版后整体缩放，隐藏时停止相机、测量、镜像和工坊刷新。3D 仅在可见时保留静态副本；角度、间距和视差帧不重新挂载业务组件。减少或关闭动画时立即完成姿态切换并关闭视差。指针离开、取消、失焦或进入属性工具时清除鼠标偏移，不改变基础角度或草稿。

## 验证入口

```sh
pnpm run test:appearance-workspace:unit
pnpm run test:appearance-workspace
pnpm run verify:materials
pnpm run typecheck
pnpm run build
```

完整外观检查包含真实 Electron 的页面、属性、预览、工坊、图标、主题保存与归档测试。`appearanceWorkspace.integration.test.ts` 直接提取 App 的标题栏、工作区和图层宿主模板及主题库的预览函数，检查入口、草稿保护、整窗图层覆盖和应用/放弃往返；其中工作区为离开决定探针，不能替代真实画布的视觉验收。

`AppearanceCapabilities.behavior.test.ts` 挂载真实工作区、属性组件、主题编辑器和窗口预览，仅隔离音乐库、播放器与原生存储。它检查搜索展开、条件参数、两类草稿交接、保存失败重试、图片导入与旧设置调用方式；`TE_CAPABILITIES_EVIDENCE` 可指定明暗主题、521px 窄窗和 22px 字号的面板截图目录。

完整窗口验收应检查主题选择、日常调整、主题制作、工坊四个入口，大字号/窄窗、2D/3D、整窗预览、保存失败和离开取消。实际运行结果以本次测试日志为准，不沿用原 PR 的历史截图或通过计数。

皮肤数据与资源边界见 [外观面板与背景皮肤](appearance-panel-layers.md)、[皮肤契约](skin-contract.md)；材质声明见 [统一材质声明](material-contract.md)。
