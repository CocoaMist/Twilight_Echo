# 标题栏图标比例修复

日期：2026-10-02。反馈截图中，左侧菜单、搜索、设置和扩展图标仍显得不协调。本轮保留已修好的固定按钮位置，调整图标本身的比例及资源规格。

## 原问题

此前只验证了图标的 20px SVG 画布和按钮几何，没有验证画布内图形的实际尺寸。真实组件测量显示：菜单图形高度为 11px，搜索约 15px，设置约 17px，扩展约 16px。齿轮在 35px 标题栏内尤其突出。账号入口的回退图标还使用字体图标。

## 修复

标题栏的返回、菜单、搜索、设置、扩展及账号图标改用 Microsoft Fluent System Icons 1.1.343 的原生 **16px Regular** 资源。保留原生路径，而不是把 20px 图形简单缩放成 16px。账号回退图标改用同族 SVG，头像也使用 16px。

`FluentIcon` 增加可选尺寸参数。指定 16px 且存在原生资源时使用 16px viewBox；未指定尺寸的现有页面保留原来的图标及尺寸继承行为。原始 SVG、来源版本和 MIT 许可保存在现有图标资源目录中。

| 图标 | 修复前图形高度 | 修复后图形高度 |
| --- | --- | --- |
| 菜单 | 11px | 9px |
| 搜索 | 约 15px | 约 13px |
| 设置 | 约 17px | 约 12px |
| 扩展 | 约 16px | 14px |

不同符号保留各自轮廓，以原生小尺寸设计减少密度差异。标题栏保持 35px；返回与左侧命令按钮保持 36px；右侧窗口按钮保持 46×35px，图标保持 12px。按钮坐标及返回区占位没有改变。

## 验证

- 专项检查通过。144 种布局仍比较 720 个返回状态采样，并增加实际 SVG 图形边界、原生 viewBox 和图形中心偏移记录。
- 检查命令图标使用 16px 原生资源；图形宽、高处于 9～14px，图形中心相对按钮中心的偏移不超过 0.6px，保留不同轮廓的官方设计。
- 应用回归 404/404、修改源码的代码及格式检查、类型检查、生产构建和渲染体积检查通过。
- 使用隔离的真实组件生成修复前后两倍放大渲染图，并人工检查；未使用 computer use。图像来自独立的离屏渲染，不代表主程序的实际屏幕或混合 DPI 验收。

后续 UI Lab 应同时记录图标画布和图形自身边界，避免再次以“画布相同”作为视觉协调的充分依据。
