# 本体更新

更新采用完整 Windows NSIS 安装包。Electron、前端与原生音频组件随安装包一起升级。
macOS / Linux 显示新版本与发布页入口，不执行 Windows 安装流程。

## 职责

- `src/main/app/appUpdateService.ts`：Electron 窗口广播、安装程序启动与定时检查。
- `appUpdateManager.ts`：任务互斥、状态快照、偏好、通知与升级结果确认。
- `appUpdateRelease.ts` / `appUpdateHelpers.ts`：GitHub 元数据、ETag、SemVer、平台资源及校验和解析。
- `appUpdateDownload.ts`：流式下载、超时、续传、校验和原子提交。
- `appUpdateRepository.ts`：更新记录、备份恢复与受限的缓存清理。
- `useAppUpdateStore.ts`：全局订阅与操作，引用计数释放监听，修订号防止旧快照覆盖新进度。
- `AppUpdatePanel.vue`：更新说明、下载进度、安装和提醒设置。

## 版本与发布要求

使用 `major.minor.patch` SemVer 标签，允许 `v` 前缀。稳定频道排除 GitHub prerelease
及带预发布后缀的标签；测试频道允许预发布并按 SemVer 选择版本。稳定频道优先使用
GitHub `releases/latest`，没有正式 Release 时回退到列表；测试频道读取最近 100 条 Release。
客户端只升级到高于当前版本的版本，不自动降级。

Windows 安装包需包含有效的文件大小与 SHA-256。优先读取 GitHub asset digest，
其次是说明中精确匹配文件名的校验记录，最后是同名 `.sha256` / `.sha256.txt` 或
`SHA256SUMS` / `checksums.txt`。只有安装包的同名校验文件允许单独一行裸哈希。
缺失校验和时拒绝下载；多文件校验清单不能回退取第一条哈希。

当前 Windows 发布策略仍为未签名安装包。SHA-256 用于完整性校验，界面如实说明
SmartScreen / UAC 提示，不声称安装包具有代码签名。

## 下载、取消与恢复

状态保存在 `userData/updates/state.json`，沿用原子 JSON 写入及备份恢复。
安装包文件名由预期哈希和发布文件名生成，不接受渲染进程提供的安装路径。
已下载包单独绑定版本、名称、URL、大小与预期哈希，不受后续检查覆盖。

下载写入 `.part`；中断保留部分内容，下一次显式下载使用 Range 续传。
收到 206 必须确认起点和总大小；收到 200 则重新写入完整文件。下载累计大小不得
超过发布记录。完成后读取文件计算 SHA-256，匹配后才重命名为安装包。
重启恢复的完整包也必须重新校验。

元数据请求最多等待 10 秒；下载连接或连续无数据最多等待 30 秒。
瞬态网络错误、408、5xx 最多尝试 3 次，间隔 1、2 秒；限流、磁盘错误、无效元数据
和校验失败需要用户处理后重试。进度广播约每 250 毫秒一次，包含速度和剩余时间。
取消仅发出中止信号，任务清理完成才释放锁；重试不能与旧任务重叠。

清理仅针对更新目录内由更新器生成的包和 `.part` 文件，不递归删除目录。
启动时保留当前候选与已就绪包，下载新包后移除旧缓存。

## 检查与提醒

打包应用启动 30 秒后允许后台检查。默认每天一次，可选每 6 小时或每 3 天，
也可以关闭。后台失败至少间隔 30 分钟再尝试，不反复弹出失败通知。
开发环境不自动联网检查。后台检查只提示版本，不自动下载或安装。
“明天提醒”抑制提醒 24 小时；“跳过此版本”针对具体版本。手动检查恢复提醒。
所有偏好持久化；切换频道清空旧候选，已验证下载包保留供用户决定是否安装。

## 安装

用户确认后，主进程获取独占安装锁，重新校验已下载文件，等待渲染进程确认播放状态
已持久化，再写入待安装版本并打开安装器。持久化或启动失败不退出应用，可以重试。
启动成功后走应用退出流程；应用再次启动时，将当前版本与待安装版本比较。
达到目标版本才显示升级成功并清理旧缓存；仍为旧版本时显示待完成安装提示。

启动安装器成功不代表安装已经完成。真实 NSIS 覆盖安装、SmartScreen / UAC、
安装器取消及原生组件恢复仍需在打包应用中完成发布前烟测。

## 验证

运行 `pnpm run test:app-update`，覆盖版本排序、校验和选择、ETag、任务并发、Range、
超时重试、缓存恢复、安装前校验、持久化失败、提醒偏好、监听释放和 Electron 页面交互。
同一组测试也接入 `test:app`。测试使用临时目录和模拟安装器，不安装任何真实软件。
